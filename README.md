# SQL Data Analysis

A small SQL practice project analyzing fictional case records.

## Contents
- `data/cases.csv`: fictional sample dataset
- `sql/analysis.sql`: table definition and example queries

## How to use
1. Create a database in MySQL.
2. Run the `CREATE TABLE` statement in `sql/analysis.sql`.
3. Import `data/cases.csv` into the `cases` table.
4. Run the SELECT queries to analyze case status and document counts.

## Skills demonstrated
SQL table creation, filtering, grouping, aggregation, and sorting.

All case and client names are fictional.
